# @Jully_Ch Portfolio

Портфолио UX/UI-дизайнера Юлии Черношей.

Сайт включает:

- главную страницу;
- кейс LINKA;
- кейс WMS/TSD;
- интерактивный архив работ;
- светлую и тёмную темы;
- адаптивную вёрстку, анимации и видео.

## Публикация

Сайт автоматически собирается и публикуется в GitHub Pages после каждого
изменения ветки `main`. Основной адрес: <https://jully-design.ru>.

## Локальная сборка

```bash
npm ci
npm run build:static
```

Готовые статические файлы появятся в папке `out`.
